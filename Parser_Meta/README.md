# 🚀 Улучшения Parser_Meta

## ✨ Что добавлено:

### 1. **Параллельная обработка**
- ⚡ Обрабатывает до 5 URL одновременно (конфигурируется)
- 🚀 Скорость увеличена в ~5 раз
- 📦 Пакетная обработка с задержками между пакетами

**Было:** 100 URL × 2 сек = 200 секунд  
**Стало:** 100 URL ÷ 5 параллельных × 2 сек = ~40 секунд

### 2. **Расширенные мета-данные**
Теперь собирается:
- ✅ `title` - заголовок страницы
- ✅ `description` - мета-описание
- ✅ `keywords` - ключевые слова
- ✅ `h1` - первый заголовок H1
- ✅ `og:title` - Open Graph заголовок
- ✅ `og:image` - Open Graph изображение
- ✅ `canonical` - канонический URL
- ✅ `robots` - мета robots
- ✅ `viewport` - настройки viewport
- ✅ `charset` - кодировка страницы
- ✅ `statusCode` - HTTP код ответа
- ✅ `error` - описание ошибки (если есть)
- ✅ **Полный скриншот страницы** (`fullPage: true`) → `Result/screenshots/`
- ✅ **Редирект**: был ли редирект, код (или цепочка кодов через `→`, если хопов несколько) и финальный URL после всех редиректов

### 1.1 Скриншот и редирект

Для каждого URL сохраняется скриншот всей страницы целиком (не только видимой области) в `Result/screenshots/<домен_путь>.png`. Имя файла — санитизированный URL (без протокола, спецсимволы → `_`).

Редирект определяется через `response.request().redirectChain()` — это реальная цепочка HTTP-редиректов (301/302/307/308), а не переход по ссылке в самом документе. В CSV попадают три колонки:
- **Редирект** — «Да»/«Нет»
- **Код редиректа** — код(ы) хопов, например `307` или `301 → 302`
- **Страница после редиректа** — URL, на котором скрипт оказался в итоге (пусто, если редиректа не было)

### 3. **Улучшенная обработка ошибок**
- 🔍 Детальное логирование каждого URL
- ⚠️ Сохранение ошибок в CSV
- 📊 Статистика успешных/неуспешных запросов
- 🎯 Продолжение работы при ошибках

### 4. **User-Agent и безопасность**
- 🤖 Установка реалистичного User-Agent
- 🛡️ Флаги безопасности для headless режима
- ⏱️ Настраиваемый таймаут

### 5. **Удобство использования**
- 🎨 Цветной вывод (chalk)
- 📁 Результаты в папке `Result/`
- 📅 Имя файла с датой: `meta_data_2026-01-16.csv`
- 🔄 Удаление дубликатов URL
- 💬 Поддержка комментариев в файле (строки с `#`)

### 6. **Производительность**
- ⚡ Параллельные браузеры
- 🔄 Повторное использование браузера в пакете
- ⏱️ Оптимальные задержки
- 📊 Статистика времени выполнения

### 7. **Конфигурация**
Легко настраивается в начале файла:
```javascript
const CONFIG = {
    PARALLEL_LIMIT: 5,        // Количество параллельных браузеров
    TIMEOUT: 30000,           // Таймаут запроса (мс)
    BROWSER_HEADLESS: true,   // Режим без GUI
    USER_AGENT: '...'         // Custom User-Agent
};
```

## 🔧 Рекомендации по настройке:

### Для быстрой обработки:
```javascript
PARALLEL_LIMIT: 10,  // Больше параллельных браузеров
TIMEOUT: 15000,      // Короче таймаут
```

### Для надежности:
```javascript
PARALLEL_LIMIT: 3,   // Меньше нагрузка
TIMEOUT: 60000,      // Больше времени на загрузку
```

### Для отладки:
```javascript
BROWSER_HEADLESS: false,  // Видимый браузер
PARALLEL_LIMIT: 1,        // По одному
```
