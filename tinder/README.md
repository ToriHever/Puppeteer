# tinder — ручной отбор доноров

Браузер по очереди открывает сайты из `sites.txt`. Вы смотрите страницу и жмёте **ДА** (подходит как донор) или **НЕТ**. Ответ записывается, сразу открывается следующий сайт.

## Запуск

```bash
node tinder.js
```

## Как работает

1. Читает домены из `sites.txt` (по одному на строку, строки с `#` игнорируются).
2. Пропускает домены, которые уже есть в `tinder_result.csv`, поэтому остановить и продолжить можно в любой момент.
3. Запускает Chrome с окном (не headless) и открывает `http://<домен>`.
4. Поверх страницы внизу рисуется панель: **✕ НЕТ (←)**, номер сайта `n/всего`, **ДА ✓ (→)**. Клавиши ← и → делают то же самое.
5. Любой ответ дописывается в `tinder_result.csv` (`domain;relevant`, значения `да` / `нет`), затем открывается следующий домен.
6. Если сайт не загрузился за 30 секунд, он записывается как `ошибка` и пропускается без вашего участия.

## Расширения

Распакованные расширения кладутся в `extensions/<имя>/` (внутри `manifest.json`), подключаются автоматически при запуске. Сейчас установлено **Redirect Path** (цепочка редиректов и коды ответа).

Профиль браузера хранится в `.profile/`: настройки расширений и входы в аккаунты сохраняются между запусками. Папка не нужна в git.

## Файлы

- `tinder.js` — скрипт.
- `sites.txt` — список доменов.
- `tinder_result.csv` — результат.
- `extensions/` — расширения.
