# Search Links Parser

Puppeteer-скрипт для проверки списка страниц на наличие ссылок/упоминаний целевых доменов.
Умеет либо взять список URL из файла, либо сам собрать их из первых N страниц выдачи Google по запросу.

## Что делает

Для каждой проверяемой страницы скрипт:
1. Открывает её headless-браузером.
2. Ищет ссылки (`<a href>`), ведущие на домены из `TARGET_DOMAINS`.
3. Ищет текстовые упоминания по regex из `TEXT_PATTERNS` (по умолчанию `ddos-guard` / `ddos guard`), которые встречаются в тексте страницы **без** ссылки.
4. Пытается определить дату страницы (публикации/обновления).
5. Всё складывает в CSV в папке `Results/`.

Настройки — вверху `parser.js`:

```js
const TARGET_DOMAINS = ['ddos-guard.ru', 'ddos-guard.net', /* ... */];
const TEXT_PATTERNS = [/ddos[-\/]?guard/i];
const EXCLUDED_DOMAINS = ['accounts.google.com', 'maps.google.com', /* ... */];
```

## Два режима запуска

### 1. Список URL из `pages.txt` (старый режим)

Если поисковый запрос не передан — скрипт читает `pages.txt` (по одному URL на строку, строки с `#` игнорируются) и проверяет их все.

```bash
node parser.js
```

### 2. Поиск по запросу (сам собирает URL из выдачи Google)

Если передан запрос — скрипт сам открывает Google, проходит по первым 10 страницам выдачи (`&start=0,10,20…`), собирает URL найденных результатов и уже их проверяет — `pages.txt` в этом случае не используется.

```bash
# запрос аргументом командной строки
node parser.js "site:example.ru ddos"

# ограничить количество страниц выдачи (по умолчанию 10)
node parser.js "site:example.ru ddos" --pages=5
```

Либо впишите запрос в `query.txt` (первая непустая строка без `#`) и запустите без аргументов:

```bash
node parser.js
```

Приоритет: аргумент командной строки → `query.txt` → `pages.txt`.

#### Защита от капчи Google

Сбор выдачи идёт в **видимом** (headful) окне браузера:
- Куки Google подгружаются из `scripts/cookies/google.json` (если файл существует) — снижают риск капчи.
- Если Google реально показал капчу (редирект на `google.com/sorry/`) — скрипт останавливается, просит решить капчу в открытом окне и нажать Enter в консоли, затем сохраняет куки обратно в `scripts/cookies/google.json` и продолжает.
- Если результатов на странице мало, но капчи нет (значит просто не совпали селекторы с текущей вёрсткой Google) — скрипт **не** останавливается, а сохраняет HTML страницы в `debug/search_page_N.html` для диагностики.

Извлечение ссылок из выдачи идёт в три стратегии (классические блоки `.g`, разбор от `<h3>`, и запасной сбор всех внешних ссылок) — используется та, что дала больше результатов, чтобы редкая вёрстка Google не давала ложные "0 результатов".

## Дата страницы

В финальный CSV добавлены две колонки с датой:

- **`page_date`** — дата, извлечённая с самой проверяемой страницы (работает в обоих режимах). Источники по приоритету:
  `dateModified`/`article:modified_time` → `datePublished`/`article:published_time` (meta-теги и JSON-LD, включая `@graph`) → `<time datetime="...">` → заголовок ответа `Last-Modified`.
- **`snippet_date`** — дата, которую сама выдача Google показывает перед описанием результата (например «15 мар. 2024 г. —», «3 дня назад —»). Заполняется только в режиме поиска по запросу и только если Google её показал.

## Файлы и папки

```
serch_links/
├── parser.js              ← основной скрипт
├── pages.txt               ← список URL для проверки (режим 1)
├── query.txt               ← поисковый запрос (режим 2, если не передан аргументом)
├── scripts/cookies/google.json  ← куки Google (создаётся/обновляется автоматически)
├── debug/                  ← HTML-дампы страниц выдачи при подозрении на смену вёрстки
├── Results/
│   ├── search_urls_<запрос>_<дата>.csv  ← сырой список URL, собранных из выдачи
│   ├── results_<...>_<дата>.csv         ← найденные ссылки/упоминания
│   └── errors_<...>_<дата>.csv          ← страницы, которые не удалось проверить
└── run_parser.bat          ← запуск через блокнот (режим pages.txt)
```

## Результат (`results_*.csv`)

| Колонка | Описание |
|---|---|
| `source_page` | проверяемая страница |
| `link_url` | найденная ссылка на целевой домен (или `Нет ссылки` для текстового упоминания) |
| `link_text` | текст ссылки или фрагмент текста с упоминанием |
| `matched_domain` | какой домен из `TARGET_DOMAINS` совпал, либо `текстовое упоминание` |
| `page_date` | дата страницы (см. выше) |
| `snippet_date` | дата из сниппета Google (только в режиме поиска) |
| `checked_at` | когда проверено (ISO-время) |

`errors_*.csv` содержит страницы, которые не открылись (HTTP-ошибка, таймаут, капча/блокировка).
