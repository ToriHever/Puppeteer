# TF-анализ (SEO)

Сравнивает текст своей страницы с конкурентами из ТОП-10 по запросу: количество слов/символов и частоту словоформ (по леммам), чтобы показать недо- и переоптимизированные слова.

Многие сайты и сама выдача Google/Яндекс блокируют автоматический парсинг, поэтому исходные HTML-страницы (свою и конкурентов) вы сохраняете вручную из браузера — так гарантированно проходит любая защита от ботов. Анализ (лемматизация, TF-статистика, сравнение) делается уже локально по этим файлам.

## Установка

1. Скачайте бинарник Yandex Mystem для вашей ОС с официальной страницы: https://yandex.ru/dev/mystem/
2. Положите его в `tf_analysis/bin/mystem.exe` (Windows) или `tf_analysis/bin/mystem` (Linux/macOS).
   Либо укажите путь через переменную окружения `MYSTEM_PATH`.
3. Зависимости отдельно ставить не нужно — модуль использует `puppeteer`/`puppeteer-extra` из корня проекта.

## Использование

1. Сами определите ТОП-10 конкурентов по запросу (в Google/Яндекс вручную).
2. Для каждого запроса создайте папку `tf_analysis/input/<любое-имя-папки>/` и положите в неё:
   - `query.txt` — сам запрос, опционально + свои главные/LSI-слова (см. ниже);
   - `own.html` — HTML вашей страницы;
   - остальные `*.html` — HTML страниц конкурентов (любые имена, кроме `own.html`, сколько угодно файлов).

   Как сохранить страницу: откройте её в браузере → `Ctrl+S` → выберите **«Веб-страница, только HTML»** → сохраните под нужным именем в нужную папку.

   Либо — если сайты не блокируют автоматические заходы — используйте `save_html.js` (см. ниже), чтобы не сохранять вручную.

   Формат `query.txt` — первая строка это запрос, дальше опционально секции `[Главные]` и `[LSI]`
   со словами/фразами **в исходной форме** (мы сами их лемматизируем и сопоставим с текстом страниц),
   через запятую или по одной на строку:
   ```
   защита сайта от ddos

   [Главные]
   защита сайта, ddos атака

   [LSI]
   файрвол, хостинг, cdn, dns, трафик
   ```
   Слова из этих секций в отчёте `lemma_report.csv` попадают в колонку «Важность» (Главное/LSI) и
   всегда показываются, даже если реально встречаются реже, чем у 30% конкурентов (порог `LEMMA_MIN_COVERAGE_RATIO`
   для остальных, «органических» лемм, не применяется к вручную помеченным).

   Пример:
   ```
   tf_analysis/input/ddos-protection/
     query.txt
     own.html
     competitor1.html
     competitor2.html
     ...
   ```
3. Запустите:
   ```
   node tf_analysis/index.js
   ```
4. Результаты — в `results/<slug-запроса>/lemma_report.csv` и `summary.csv`.

## Автосохранение HTML (`save_html.js`)

Заменяет ручной Ctrl+S для сайтов, которые не блокируют автоматические заходы — для остальных всё ещё нужен ручной способ выше.

1. Впишите список в `scripts/save_html_urls.txt`. Строка, которая **не похожа на URL**, — это название группы = имя папки в `input/` (создастся, если её ещё нет; если есть — сохранит в неё). Все URL после неё, до следующего такого названия, относятся к этой группе. Пустые строки внутри группы не важны. Одну строку в группе можно пометить префиксом `own:` — она сохранится как `own.html`, остальные — по домену:
   ```
   защита сервера от ddos
   own: https://ddos-guard.ru/web-protection
   https://sweb.ru/cloud/DDoS-protection/
   https://selectel.ru/services/protection/

   ещё одна группа — своя отдельная папка
   own: https://example.ru/page
   https://competitor.ru/page
   ```
2. Запустите (имя папки вводить не нужно — берётся из списка):
   ```
   node tf_analysis/save_html.js
   ```
3. Своя страница сохранится как `own.html`, конкуренты — по имени домена (`sweb-ru.html`, при повторе домена — `sweb-ru_2.html`). Если какая-то страница не сохранилась (бот-защита) — скрипт сообщит об этом и не остановит обработку остальных URL/групп; досохраните такую страницу вручную.
4. `query.txt` скрипт не создаёт — добавьте его в каждую готовую папку сами (см. формат выше), затем запускайте `node tf_analysis/index.js`.

## Как это работает

1. `utils/inputFolders.js` — сканирует `input/*/`, находит `query.txt` + `own.html` + HTML конкурентов в каждой папке.
2. `lib/fetchPageText.js` — открывает локальный HTML-файл через puppeteer (`file://`), вырезает шум (nav/header/footer/script и т.п.), считает слова/символы.
3. `lib/lemmatizer.js` — лемматизирует текст через Mystem.
4. `lib/tfStats.js` — считает частоты лемм, агрегирует по конкурентам (мин/среднее/медиана/макс), сравнивает со своей страницей.
5. `utils/report.js` — сохраняет CSV с BOM (корректная кириллица в Excel).

## Альтернативный (не рекомендуемый) режим — автопарсинг

`lib/fetchTop10.js` умеет получать ТОП-10 напрямую из Google/Яндекс через `multi_search_parser`, а `fetchPageText.js` поддерживает и обычные URL, не только локальные файлы. Но многие сайты блокируют автоматические заходы, поэтому основной сценарий — ручная выгрузка HTML, описанная выше. `scripts/tasks.txt` и `utils/tasks.js` оставлены в проекте на случай, если понадобится вернуться к автопарсингу.
