# Список URL/запросов для автосохранения HTML (save_html.js).
# Строки с "#" и пустые — игнорируются.
#
# Строка, которая НЕ похожа на URL (и не метка own:/query:/keywords:/url:), —
# это название группы = имя папки в input/ И первая строка её query.txt.
#
# Внутри группы:
#   own: https://...   — своя страница (own.html)
#   query:              — дальше ПОИСКОВЫЕ ЗАПРОСЫ, по одному на строку —
#                         для каждого делается РЕАЛЬНЫЙ поиск в Google/Яндекс,
#                         найденные страницы добавляются к списку для сохранения
#   keywords:           — дальше содержимое для query.txt (обычно секции
#                         [Главные]/[LSI]) — записывается КАК ЕСТЬ, без единого
#                         запроса в Google/Яндекс. НЕ путать с query: выше —
#                         это разные вещи для разных целей
#   url:                — дальше URL напрямую, по одному на строку (закрывает
#                         query:/keywords:)
#
# Пример:
# own: https://ddos-guard.ru/web-protection
# query:
# защита сервера от ddos
# keywords:
# [Главные]
# защита сервера, ddos атака
# [LSI]
# файрвол, хостинг, cdn
# url:
# https://sweb.ru/cloud/DDoS-protection/
# https://selectel.ru/services/protection/
